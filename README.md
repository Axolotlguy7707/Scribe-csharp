# Scribe
A Free, Easy Way to write

Scribe is free and open source,
meaning you can use it for any commercial
purposes! Even if your book becomes a
bestseller, you don't owe me anything!

Scribe is Free And Open Source Software (FOSS) and always will be.

## Contribute
There are many ways you can help the development of this project!
### Donating
You can donate on itch.io! Even the smallest donation can help support the project
### Mentioning
If you write a successful book, please mention the project.
You don't have to, but it would mean the world if you did.
### Code Contributions
Have Experience with .NET/C#? The Software is written in C#,
in the [Avalonia](https://avaloniaui.net/) Framework. Feel free to add code!
